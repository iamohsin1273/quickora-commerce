# MASTER BUILD PROMPT: QUICKORA — FULL-STACK QUICK-COMMERCE PLATFORM

## 1. YOUR ROLE AND OBJECTIVE

You are a principal full-stack software architect, senior UI/UX designer, senior React engineer, Node.js backend engineer, database architect, QA engineer, security engineer, and DevOps engineer.

Your mission is to DESIGN, IMPLEMENT, TEST, DOCUMENT, AND PACKAGE a complete, modern quick-commerce platform inspired by the convenience and user experience of Instamart, Blinkit, and Zepto.

Build an original product called **QUICKORA**.

This is not a request for a tutorial, architecture proposal, wireframe, static mockup, or code snippets. I expect a real, runnable, full-stack repository with a beautiful user interface, a functional backend, persistent database storage, realistic seed data, working user journeys, automated tests, Docker configuration, and a ZIP archive containing the complete project.

You have permission to create and edit project files, execute terminal commands, install dependencies when appropriate, run the application, inspect errors, fix them, and package the final repository.

Do not stop after creating the frontend. Do not leave the core functionality as TODO comments. Do not claim that something works unless you have implemented and tested it.

If you encounter a technical limitation, choose a practical alternative, document it, and continue.

## 2. PRODUCT VISION

QUICKORA is a premium Indian hyperlocal quick-commerce platform for delivering groceries, snacks, beverages, fruits, vegetables, dairy, household supplies, personal care products, and other daily essentials.

The application should feel like a real startup product that could be demonstrated to investors, recruiters, customers, and engineering teams.

Target market: Indian urban customers.

Default currency: INR (₹).

Default location: Chennai, Tamil Nadu, India.

Default language: English.

Design for desktop, tablet, and mobile, with a mobile-first customer shopping experience.

Use original branding and original interface layouts. Do not copy proprietary logos, assets, or exact screens from Blinkit, Zepto, or Swiggy Instamart.
